COMPUTER BASICS

We start where you are.

You do not need to know computer language before you begin. These resources introduce the everyday skills that form the foundation for using a laptop computer with confidence. Windows laptops are the primary platform, and Chromebook users are welcome.

THE LEARNING JOURNEY

From “I do not know” to “I can do this.”

Each skill builds on the one before it. Take your time, practice, ask questions, and return to a lesson whenever you need it.

LESSON 01

Getting Started

Before we can use a computer, we need to become comfortable with the computer itself.

We demonstrate

  • Parts of a laptop computer
  • Power button and safe startup
  • Desktop and screen basics
  • Windows and applications
  • Safe shutdown

Practice goal

By the end of this lesson, you should be able to identify the basic parts of your computer and start and shut it down with confidence.

LESSON 02

Mouse & Keyboard

The mouse and keyboard are how we communicate with the computer.

We demonstrate

  • Pointing and moving the mouse
  • Single and double clicking
  • Scrolling
  • Typing letters and numbers
  • Space, Enter, Backspace, Shift, and other useful keys

Practice goal

Practice moving, clicking, scrolling, and typing until these actions begin to feel natural.

LESSON 03

Files & Folders

Your computer needs a way to organize the things you create and save.

We demonstrate

  • What a file is
  • What a folder is
  • Creating and naming folders
  • Saving a document
  • Finding, opening, and renaming files

Practice goal

Create a simple folder, save a practice document, close it, and find it again.

LESSON 04

Internet Basics

The internet becomes much less intimidating when we understand the basic pieces.

We demonstrate

  • Opening a web browser
  • Using the address bar
  • Searching for information
  • Opening links and tabs
  • Understanding websites and web addresses

Practice goal

Open a browser, search for something you want to know, open a result, and return to your search.

LESSON 05

Email & Communication

Email is one of the most useful everyday computer skills.

We demonstrate

  • Understanding an inbox
  • Writing and sending a message
  • Replying to an email
  • Recognizing attachments
  • Basic email organization

Practice goal

Understand the path of a basic email from writing to sending, receiving, reading, and replying.

LESSON 06

Online Safety

Learning how to use technology also means learning how to protect yourself.

We demonstrate

  • Creating and protecting strong passwords
  • Recognizing suspicious links
  • Understanding phishing and common scams
  • Protecting personal information
  • Pausing before responding online

Practice goal

Build the habit of stopping, looking carefully, and thinking before clicking, downloading, replying, or sharing information.

REMEMBER

You are learning a skill, not proving yourself.

It is normal to forget a step. It is normal to ask the same question twice. The goal is not to rush. The goal is to understand enough that you can keep going.
