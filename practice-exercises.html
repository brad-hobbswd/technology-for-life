PRACTICE EXERCISES

Learning happens when you try it yourself.

These exercises are designed for your own computer. Take your time, repeat the steps, and remember that making a mistake is part of learning.

HOW TO USE THESE EXERCISES

Practice one skill at a time.

Choose an exercise that matches what you are learning. Read the directions before you begin, then work through each step on your own computer.

You do not have to finish everything in one sitting. If you get stuck, write down where you stopped and bring the question to class.

PRACTICE LIBRARY

Start practicing

01

Mouse Practice

Build comfort with pointing, clicking, double clicking, dragging, dropping, and scrolling.

Try it
  1. Move the pointer to an icon.
  2. Click once.
  3. Double click an application.
  4. Scroll up and down.
  5. Drag an item to a new place when appropriate.

Success looks like: You can control the pointer without feeling rushed.

02

Keyboard Practice

Practice typing and using the keys you will use most often.

Try it
  1. Open a simple text document.
  2. Type your first and last name.
  3. Type a complete sentence.
  4. Use Shift for a capital letter.
  5. Use Space, Enter, and Backspace.

Success looks like: You can type a short message and correct a simple mistake.

03

Desktop Practice

Practice opening, moving, minimizing, maximizing, and closing a program window.

Try it
  1. Open a program.
  2. Move its window.
  3. Minimize it.
  4. Bring it back.
  5. Close the program.

Success looks like: You understand that a program can be open without filling the whole screen.

04

File Practice

Practice creating a folder and saving a document so you can find it later.

Try it
  1. Create a folder named Practice.
  2. Open a document program.
  3. Type a short sentence.
  4. Save it inside Practice.
  5. Close and find the file again.

Success looks like: You can save something and find it again without starting over.

05

Internet Practice

Practice using a browser, search, links, and tabs.

Try it
  1. Open a web browser.
  2. Search for a topic you know.
  3. Open a result.
  4. Return to your search.
  5. Open a new tab.

Success looks like: You can move between a search, a website, and a new tab.

06

Email Practice

Learn the basic path of writing, sending, receiving, and replying to a message.

Try it
  1. Open your email service.
  2. Find the inbox.
  3. Compose a practice message.
  4. Review the recipient and message.
  5. Practice replying to a message.

Success looks like: You understand the difference between an inbox, a new message, and a reply.

07

Safety Practice

Practice stopping and looking carefully before responding to an online message.

Try it
  1. Read a sample message carefully.
  2. Look at the sender.
  3. Look for urgent or threatening language.
  4. Notice suspicious links or requests.
  5. Decide whether you should stop and ask for help.

Success looks like: You pause before clicking or sharing information.

IF YOU GET STUCK

Stop. Breathe. Try again.

You do not need to be embarrassed when something does not work. Write down what you were trying to do and what happened. That gives you something useful to bring back to class.

1. Read the step again.Sometimes the answer is already there.
2. Try it slowly.There is no timer on learning.
3. Write down the problem.Your notes can help you remember what happened.
4. Ask for help.Bring the question to class.

KEEP GOING

You do not have to get it right the first time.

Every time you practice, you are building familiarity. Familiarity becomes confidence, and confidence makes the next step easier.
